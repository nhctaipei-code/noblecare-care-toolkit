譯文由 Google 翻譯官方介面輔助產生，另有詞彙校正、欄位完整性與數值檢查。這些技術檢查不等同於英文、越南文、印尼文專業人員逐項審稿。介面保留此說明與原文對照。

內容依原作的臺灣居家服務情境整理，不改變人員執業範圍，也不取代機構 SOP、核定服務內容、督導及醫事專業人員指示。原作所列法規與參考資料保留為原作引用，並非本專案逐一重新查證或背書。緊急狀況先求助，不要等待 AI。

## 技術

純靜態 HTML/CSS/JavaScript，沒有新增資料庫、追蹤碼、第三方執行期翻譯服務、密碼或憑證。語言與收藏只存在本機瀏覽器。關閉或限制本機儲存不影響閱讀。

GitHub Pages 從 `main` 根目錄發布。`index.html`、`style.css`、`ui.js`、`app.js`、`data.js` 為執行所需檔案。可用任意靜態伺服器於本機預覽。

公開網站與 Portal 入口部署是兩個獨立階段；以實際發布紀錄為準，不因推送儲存庫就視為 Portal 已更新。
